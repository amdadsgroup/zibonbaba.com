MOBILE APP-LIKE EXPERIENCE (VERY IMPORTANT)

When users access the platform from a mobile device, the system must automatically switch to a Mobile App UI experience instead of simply shrinking the desktop website.

Requirements:

* Detect mobile devices automatically.
* Display a fully optimized mobile interface.
* Mobile experience should feel like a native Android/iOS application.
* Use bottom navigation bar similar to Amazon, Daraz, and Alibaba mobile apps.
* Full-screen mobile layouts.
* Touch-friendly buttons and interactions.
* Swipe gestures where appropriate.
* Mobile-first responsive design.
* Fast loading and optimized performance.
