# Zibonbaba.com — Phase 1 Admin Panel Prompt

Act as a **World-Class Product Designer, UI/UX Architect, Senior Full-Stack Engineer, SaaS Architect, and Enterprise Dashboard Specialist**.

Design and build a **premium, enterprise-grade Admin Panel for Zibonbaba.com**, a multi-vendor e-commerce marketplace.

The Admin Panel must be production-ready, responsive, scalable, secure, fast, and connected to real backend data. Do not create a static demo dashboard. Every major component should be structured for dynamic API integration.

# 44. MULTI-VENDOR SECURITY

A vendor must never access another vendor's data.

Admin can access platform-wide data.

Use server-side authorization and tenant isolation.

Never trust:

* Frontend vendorId
* Frontend role
* LocalStorage role
* Client-provided ownership information

Always validate ownership and permissions on the backend.

The final Admin Panel should feel like a **real enterprise SaaS control center**, not a template dashboard.

* Premium
* Minimal
* Fast
* Responsive
* Accessible
* Secure
* Data-driven
* Scalable
* Multi-vendor ready
